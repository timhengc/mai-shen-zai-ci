麦门封神榜
FIRST CONNECTION / MCP

先连接账号，
再开启你的麦门身份。

扫描下方二维码，或点击链接前往麦当劳 MCP 官方平台。登录并复制 Token 后，可返回 Agent 对话框发送，也可以写入本地配置文件。

扫码或点链接，进入官网

二维码打开的是官方页面。请在官网完成登录、激活和协议确认，再复制属于自己的 MCP Token。

打开官方平台 / 接入文档 ↗https://open.mcd.cn/mcp
01完成官网登录

点击右上角「登录」，按官网当前页面提示扫码或完成其他登录步骤。

02激活 MCP

进入「控制台」，点击激活，阅读并同意服务协议。

03复制 Token

复制控制台中的 MCP Token，使用下方任意一种方式继续。

复制后，任选一种方式继续

方式一 · 发到当前对话框

回到使用此 Skill 的 Agent 对话，把 Token 粘贴发送即可。Agent 收到后不回显，默认仅用于本次操作；不会自动保存到文件。

配置完成后，再选择年报、名片、头像或全套视觉。

方式二 · 写入配置文件

在项目根目录创建或编辑 .env 文件：

MCD_MCP_TOKEN=你的Token

也可在这里粘贴并下载 mcd-token.env，将文件放到项目根目录即可自动读取，无需改名。
